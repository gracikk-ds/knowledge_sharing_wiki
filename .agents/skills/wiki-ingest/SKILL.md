# wiki-ingest

Переноси PDF в `.md`-заметку под `wiki/` дословно. Это перенос, а не пересказ или авторская переработка.

## Главное правило

Сохраняй текст, структуру, заголовки, списки и порядок исходника. Не сокращай, не перефразируй, не переставляй, не дополняй содержание и не исправляй авторские формулировки.

Перед работой прочитай `styleguide.md`, но применяй из него только правила, нужные для корректного отображения:

- математика — LaTeX: inline `$...$`, display `$$...$$` с разделителями на отдельных строках, многострочные выкладки через `\begin{aligned}`; математические символы не оставляй в Unicode или backticks;
- картинки — `![[images/<topic>/<file>]]` сразу после абзаца, который на них ссылается;
- таблицы — Markdown-таблицы;
- frontmatter — `Created`, `Reviewed`, опционально `Keywords`; для новой непроверенной заметки ставь `Reviewed: Todo`.

Правила про язык, голос, регистр и ход объяснения к ingest не применяй.

## Инструмент

Используй `scripts/extract_pdf_images.py` из каталога активной копии скилла. Из корня репозитория выбери ровно один путь:

```bash
# Для .agents/skills/wiki-ingest
SCRIPT=.agents/skills/wiki-ingest/scripts/extract_pdf_images.py

# Для .claude/skills/wiki-ingest
SCRIPT=.claude/skills/wiki-ingest/scripts/extract_pdf_images.py
```

Зависимости объявлены по PEP 723. Запускай подкоманды через `uv run`:

```bash
uv run "$SCRIPT" text --pdf in.pdf --pages 1-5
uv run "$SCRIPT" embedded --pdf in.pdf --out-dir wiki/images/<topic> --prefix <name>
uv run "$SCRIPT" render --pdf in.pdf --pages 5 --out-dir wiki/images/<topic> --prefix <name> --bbox x0,y0,x1,y1
```

## Процесс

Веди шаги в плане задачи, если механизм плана доступен.

1. Определи topic-папку `wiki/<topic>/`, имя заметки и prefix картинок. Если это нельзя надёжно вывести из контекста, спроси пользователя. Картинки складывай в `wiki/images/<topic>/`.
2. Запусти `text` для всего PDF и классифицируй страницы по `chars`, `images`, `drawings`. Богатый текстовый слой переноси из дампа; если порядок блоков нарушен, повтори извлечение с `--mode blocks`. Статистика — эвристика: страницы со сложной вёрсткой всё равно проверяй визуально.
3. Для визуальных страниц запусти `render`, открой PNG и перенеси текст дословно, а формулы — как LaTeX. Если часть страницы нельзя прочитать надёжно, укажи точные страницы и не восстанавливай содержание по догадке.
4. Чистые растровые изображения извлекай через `embedded`. Векторные диаграммы, графики и схемы получай через `render --bbox`; bbox задавай в точках PDF по координатам блоков из `text`. Визуально проверь извлечённые файлы.
5. Собери заметку в исходном порядке. Вставь изображения на исходных местах; исправь только математику, таблицы и отображение.
6. Сверь заметку с PDF по страницам. Проверь, что ни одна страница не пропущена, все `![[...]]` указывают на существующие файлы, display math оформлена отдельными `$$`, математических символов в Unicode и backticks нет, а структура и порядок совпадают с исходником.

После изменения содержимого `wiki/` предложи применить `$wiki-reindex`.

## Деградация

Если PyMuPDF недоступен, `uv run` установит его из PEP 723. При необходимости повтори команду как `uv run --with pymupdf "$SCRIPT" ...`.
