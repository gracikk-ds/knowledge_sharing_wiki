# Google Meet

## Функциональные требования
#### Основные требования 
1. Пользователь может создавать комнаты для разговоров и делиться ссылкой на них
2. Пользователь может подключаться к комнатам по ссылке
3. Пользователи находящиеся в одной комнате могут общаться голосом в реальном времени и включать/выключать микрофон
4. Пользователи находящиеся в одной комнате имеют возможность транслировать видео в реальном времени и включать/выключать микрофон
5. Пользователи имеют возможность демонстрировать свой экран участникам комнаты в реальном времени
6. Пользователи находящиеся в одной комнате могут общаться текстом в реальном времени
####  Дополнительные требования
1. Запись встречи
2. Транскрибация встречи
3. Реакции
4. Управления участниками (mute/unmute,  комната ожидания)
