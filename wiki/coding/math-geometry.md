Math & Geometry — сборный раздел: манипуляции с матрицами in-place, аккуратная симуляция по правилам и немного теории чисел. Общих фреймворков здесь меньше, чем в [[dp-1d]] или [[graphs]], но повторяющиеся приёмы есть, и почти все они про одно: задача просит $O(1)$ дополнительной памяти, а мы кодируем служебную информацию прямо в самих данных — маркеры в первой строке, второй бит на клетку, разложение операции на простые обратимые шаги.

## Поворот матрицы на 90°: транспонирование + reverse

**Сигнал.** «Поверните квадратную матрицу на 90° по часовой in-place». Любая перестановка клеток, раскладываемая на отражения.

**Идея.** Поворот по часовой $=$ транспонирование (отражение относительно главной диагонали) $+$ reverse каждой строки. Оба шага тривиально делаются in-place, а композиция двух отражений даёт нужный поворот; против часовой — транспонирование $+$ reverse столбцов. Альтернатива — крутить «кольцами»: для каждой клетки внешнего слоя циклически переставить четыре элемента и сдвигаться внутрь; работает, но требует больше индексной аккуратности.

```python
def rotate(matrix: list[list[int]]) -> None:
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):   # transpose: swap across the diagonal
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()
```

**Типовые задачи:** Rotate Image.

Сложность: $O(n^2)$ по времени, $O(1)$ по памяти.

## Spiral Matrix: четыре сжимающиеся границы

**Сигнал.** «Обойдите матрицу по спирали», «заполните матрицу по спирали» — любой обход слоями снаружи внутрь.

**Идея.** Держим четыре границы `top`, `bottom`, `left`, `right` и ходим по циклу: вправо по верхней строке, вниз по правому столбцу, влево по нижней, вверх по левому — после каждого прохода сдвигаем свою границу внутрь. Две проверки в середине цикла спасают от двойного прохода по последней строке или столбцу неквадратной матрицы — единственное место, где все ошибаются.

```python
def spiral_order(matrix: list[list[int]]) -> list[int]:
    res = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        res.extend(matrix[top][c] for c in range(left, right + 1)); top += 1
        res.extend(matrix[r][right] for r in range(top, bottom + 1)); right -= 1
        if top <= bottom:
            res.extend(matrix[bottom][c] for c in range(right, left - 1, -1)); bottom -= 1
        if left <= right:
            res.extend(matrix[r][left] for r in range(bottom, top - 1, -1)); left += 1
    return res
```

**Типовые задачи:** Spiral Matrix, Spiral Matrix II.

Сложность: $O(mn)$ — каждая клетка ровно один раз.

## Set Matrix Zeroes: первая строка и столбец как маркеры

**Сигнал.** «Обнулите строку и столбец каждого нуля in-place». Наивно нужны $O(m + n)$ памяти на множества «плохих» строк и столбцов — просят $O(1)$.

**Идея.** Эти множества и так помещаются в матрицу: первая строка хранит маркеры «обнулить столбец $c$», первый столбец — «обнулить строку $r$». Тонкость одна: первая строка и столбец — одновременно данные и маркеры, поэтому их собственное состояние («был ли там ноль») запоминаем в двух флагах до записи маркеров, а обнуляем их последними.

```python
def set_zeroes(matrix: list[list[int]]) -> None:
    rows, cols = len(matrix), len(matrix[0])
    first_row, first_col = 0 in matrix[0], any(row[0] == 0 for row in matrix)
    for r in range(1, rows):
        for c in range(1, cols):
            if matrix[r][c] == 0:
                matrix[r][0] = matrix[0][c] = 0     # markers
    for r in range(1, rows):
        for c in range(1, cols):
            if matrix[r][0] == 0 or matrix[0][c] == 0:
                matrix[r][c] = 0
    if first_row: matrix[0] = [0] * cols
    if first_col:
        for row in matrix: row[0] = 0
```

**Типовые задачи:** Set Matrix Zeroes.

Сложность: $O(mn)$ по времени, $O(1)$ по памяти.

## Симуляция in-place: два бита на клетку (Game of Life)

**Сигнал.** Все клетки обновляются **одновременно** по правилам, зависящим от соседей, а обновлять просят in-place. Наивная перезапись ломает подсчёт соседей: часть уже в новом состоянии.

**Идея.** Значения клеток маленькие — в одном числе помещаются оба поколения: младший бит хранит старое состояние, второй бит — новое (связь с [[bit-manipulation]]). Соседей считаем через `& 1` (видим только старое поколение), будущее пишем через `|= 2`, вторым проходом сдвигаем всё на бит вправо. Трюк «закодировать переход состояния числом» работает в любой клеточной симуляции.

```python
def game_of_life(board: list[list[int]]) -> None:
    rows, cols = len(board), len(board[0])
    for r in range(rows):
        for c in range(cols):
            live = sum(board[r + dr][c + dc] & 1        # old state = low bit
                       for dr in (-1, 0, 1) for dc in (-1, 0, 1)
                       if (dr or dc) and 0 <= r + dr < rows and 0 <= c + dc < cols)
            if live == 3 or (board[r][c] & 1 and live == 2):
                board[r][c] |= 2                        # new state = second bit
    for row in board:
        row[:] = [v >> 1 for v in row]
```

**Типовые задачи:** Game of Life.

Сложность: $O(mn)$ по времени, $O(1)$ по памяти.

## Binary exponentiation

**Сигнал.** Возвести в степень $n$ порядка $10^9$; matrix power; «быстро повторить ассоциативную операцию $n$ раз».

**Идея.** Раскладываем показатель по битам: $x^{13} = x^8 \cdot x^4 \cdot x^1$, потому что $13 = 1101_2$. На каждом шаге квадрируем базу ($x \to x^2 \to x^4 \to \ldots$) и домножаем результат, когда очередной бит $n$ равен единице. Отрицательная степень — это $1/x$ в степени $-n$. Приём работает для любой ассоциативной операции, включая умножение матриц.

```python
def my_pow(x: float, n: int) -> float:
    if n < 0:
        x, n = 1 / x, -n
    res = 1.0
    while n:
        if n & 1:
            res *= x
        x, n = x * x, n >> 1    # square the base, shift the exponent
    return res
```

**Типовые задачи:** Pow(x, n).

Сложность: $O(\log n)$.

## Работа с цифрами числа

**Сигнал.** «Разверните число», «палиндром ли число без строки», «прибавьте единицу к числу-массиву» — всё, где число обрабатывается поразрядно.

**Идея.** Универсальный цикл: $x \bmod 10$ снимает младшую цифру, целочисленное деление на $10$ отбрасывает её, $\text{rev} \cdot 10 + d$ пристраивает к результату. В Reverse Integer после разворота проверяем выход за $[-2^{31}, 2^{31} - 1]$ (в Python переполнения нет, но проверку спросят). В Palindrome Number достаточно развернуть половину числа и сравнить половины. В Plus One идём с конца массива и несём перенос, пока цифра равна девяти.

```python
def reverse(x: int) -> int:
    sign, x, rev = (-1 if x < 0 else 1), abs(x), 0
    while x:
        rev, x = rev * 10 + x % 10, x // 10     # pop last digit, push onto rev
    rev *= sign
    return rev if -2**31 <= rev <= 2**31 - 1 else 0
```

**Типовые задачи:** Reverse Integer, Palindrome Number, Plus One.

Сложность: $O(\log_{10} n)$ — по числу цифр.

## Happy Number: детекция цикла

**Сигнал.** Итерируем функцию $n \to f(n)$ и спрашиваем, зациклится ли процесс. Последовательность значений — неявный linked list, где $f$ играет роль `next`.

**Идея.** Сумма квадратов цифр ограничена (для $n < 10^{13}$ это максимум $13 \cdot 81$), поэтому последовательность обязана либо прийти в $1$, либо зациклиться. Цикл ловим set-ом посещённых значений или fast & slow pointers Флойда — ровно как в [[linked-list]], только «указатель» здесь — само число, и памяти нужно $O(1)$.

```python
def is_happy(n: int) -> bool:
    step = lambda m: sum(int(d) ** 2 for d in str(m))
    slow, fast = n, step(n)
    while fast != 1 and slow != fast:
        slow, fast = step(slow), step(step(fast))
    return fast == 1
```

**Типовые задачи:** Happy Number.

Сложность: каждый шаг $O(\log n)$, цикл короткий — практически константа.

## Multiply Strings: школьное умножение по разрядам

**Сигнал.** Числа даны строками и не влезают в машинное слово (в Python влезают, но спрашивают именно ручной алгоритм).

**Идея.** Умножение в столбик: цифра $i$ первого числа на цифру $j$ второго даёт вклад ровно в позиции $i + j$ (старшая часть) и $i + j + 1$ (младшая) результата — этот инвариант избавляет от возни со сдвигами строк. Заводим массив длины $m + n$ (длиннее произведение не бывает), накапливаем вклады и переносы прямо в нём, в конце срезаем ведущие нули.

```python
def multiply(num1: str, num2: str) -> str:
    if "0" in (num1, num2): return "0"
    res = [0] * (len(num1) + len(num2))
    for i in range(len(num1) - 1, -1, -1):
        for j in range(len(num2) - 1, -1, -1):
            total = int(num1[i]) * int(num2[j]) + res[i + j + 1]
            res[i + j + 1] = total % 10
            res[i + j] += total // 10       # carry into the higher position
    return "".join(map(str, res)).lstrip("0")
```

**Типовые задачи:** Multiply Strings, Add Strings (та же схема без вложенного цикла).

Сложность: $O(mn)$.

## Detect Squares: hashmap точек + перебор диагоналей

**Сигнал.** Точки на плоскости добавляются онлайн, запрос — «сколько фигур можно собрать с данной точкой». Геометрия сводится к подсчёту, то есть к [[arrays-hashing]].

**Идея.** Храним счётчик точек в hashmap. Для запроса $(x, y)$ перебираем все известные точки $(x_2, y_2)$ как кандидатов в противоположный угол **по диагонали**: годится, если $|x - x_2| = |y - y_2| \neq 0$. Две оставшиеся вершины квадрата тогда определены однозначно — $(x, y_2)$ и $(x_2, y)$ — и вклад в ответ равен произведению их счётчиков. Диагональ фиксирует квадрат, поэтому ничего не считаем дважды.

**Типовые задачи:** Detect Squares.

Сложность: $O(n)$ на запрос, где $n$ — число различных точек.

## Теория чисел: GCD и решето Эратосфена

Алгоритм Евклида: $\gcd(a, b) = \gcd(b,\ a \bmod b)$, повторяем до нуля — `while b: a, b = b, a % b` — за $O(\log \min(a, b))$. Решето Эратосфена (Count Primes): для каждого невычеркнутого простого $i \leq \sqrt{n}$ вычёркиваем кратные начиная с $i^2$ (всё меньшее уже вычеркнули меньшие простые), в Python удобно слайсом `sieve[i * i::i] = [False] * len(sieve[i * i::i])` — итого $O(n \log \log n)$.
