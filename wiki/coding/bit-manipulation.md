Bit Manipulation на Neetcode — раздел про задачи, где число рассматривается не как значение, а как массив битов. Инструментов всего пять: AND (`&`), OR (`|`), XOR (`^`), NOT (`~`) и сдвиги (`<<`, `>>`). Почти все приёмы раздела строятся на трёх тождествах: $a \oplus a = 0$, $a \oplus 0 = a$ (плюс коммутативность и ассоциативность XOR) и $n \wedge (n-1)$ — снимает младший единичный бит. Отрицательные числа хранятся в two's complement: $-n = \neg n + 1$.

Специфика Python: `int` произвольной длины, поэтому переполнения нет, а «биты» отрицательного числа концептуально тянутся влево бесконечно ($-1$ — это бесконечная строка единиц). Когда задача подразумевает 32-битную машину (Sum of Two Integers, Reverse Bits), 32 бита эмулируем маской `0xFFFFFFFF`: после каждой операции делаем `x & mask`, а в конце восстанавливаем знак, если старший бит оказался единицей.

## XOR: одиночка и пропущенное число

**Сигнал.** Все элементы встречаются парами, кроме одного; дан массив из чисел $0 \ldots n$ без одного числа; требуется $O(1)$ памяти там, где напрашивается hash set из [[arrays-hashing]].

**Идея.** XOR коммутативен и сам себе обратен: в XOR-свёртке массива пары аннигилируют по $a \oplus a = 0$, и остаётся ровно одиночка. Для Missing Number XOR-им индексы $0 \ldots n$ и все элементы — парой не находится только пропущенное. Второй путь — формула суммы $\sum_{i=0}^{n} i = \frac{n(n+1)}{2}$ минус фактическая сумма (арифметика вместо битов — связь с [[math-geometry]]).

```python
def single_number(nums: list[int]) -> int:
    res = 0
    for x in nums:
        res ^= x  # pairs cancel out
    return res

def missing_number(nums: list[int]) -> int:
    n = len(nums)
    return n * (n + 1) // 2 - sum(nums)
```

**Типовые задачи:** Single Number, Missing Number.

Сложность: $O(n)$ по времени, $O(1)$ по памяти.

## $n \wedge (n-1)$: Керниган и степени двойки

**Сигнал.** Посчитать единичные биты числа; проверить, что число — степень двойки.

**Идея.** Вычитание единицы гасит младший единичный бит и зажигает всё под ним, поэтому $n \wedge (n-1)$ возвращает $n$ без младшей единицы. Приём Брайана Кернигана: повторяем, пока не ноль, — цикл делает ровно столько итераций, сколько единиц в числе, а не 32. Степень двойки — это ровно один единичный бит, то есть $n > 0$ и $n \wedge (n-1) = 0$. Родственное тождество: $n \wedge (-n)$ *выделяет* младший единичный бит (следствие two's complement). В Python есть и встроенный `n.bit_count()`.

```python
def hamming_weight(n: int) -> int:
    count = 0
    while n:
        n &= n - 1  # drop the lowest set bit
        count += 1
    return count

def is_power_of_two(n: int) -> bool:
    return n > 0 and n & (n - 1) == 0
```

**Типовые задачи:** Number of 1 Bits, Power of Two, Counting Bits (альтернативный переход).

Сложность: $O(k)$, где $k$ — число единичных битов ($k \leq \log_2 n$).

## DP + биты: Counting Bits

**Сигнал.** Нужен popcount сразу для всех чисел $0 \ldots n$; наивные $O(n \log n)$ хочется ужать до $O(n)$.

**Идея.** Число $i \gg 1$ — это $i$ без последнего бита, и его popcount уже посчитан. Значит $dp[i] = dp[i \gg 1] + (i \wedge 1)$: берём готовый ответ и добавляем последний бит. Классическое одномерное DP по уже вычисленным меньшим состояниям — см. [[dp-1d]]. Эквивалентный переход через Кернигана: $dp[i] = dp[i \wedge (i-1)] + 1$.

```python
def count_bits(n: int) -> list[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)
    return dp
```

**Типовые задачи:** Counting Bits.

Сложность: $O(n)$.

## Reverse Bits: сборка результата по биту

**Сигнал.** Перевернуть 32-битное представление числа; собрать новое число из битов старого в другом порядке.

**Идея.** Стандартный конвейер: на каждом шаге сдвигаем результат влево, снимаем младший бит входа через $n \wedge 1$, приклеиваем его через OR и сдвигаем вход вправо. Ровно 32 итерации — фиксированная ширина слова, поэтому и константная сложность. Тот же паттерн «читаем биты с одного конца, пишем с другого» пригодится в любой задаче на перестановку битов.

```python
def reverse_bits(n: int) -> int:
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)
        n >>= 1
    return res
```

**Типовые задачи:** Reverse Bits.

Сложность: $O(w)$ при ширине слова $w = 32$, то есть $O(1)$.

## Сложение без `+`: XOR + перенос

**Сигнал.** Явный запрет на `+` и `-`; просят реализовать арифметику на битовых операциях.

**Идея.** XOR — это сложение по модулю 2 без переноса: $a \oplus b$ даёт сумму в тех разрядах, где переноса нет. Перенос возникает там, где оба бита единичные, и уезжает на разряд влево: $(a \wedge b) \ll 1$. Повторяем «сумма + перенос», пока перенос не обнулится. В Python без маски отрицательный перенос будет уезжать влево бесконечно (числа-то произвольной длины), поэтому обрезаем всё по `0xFFFFFFFF`, а в конце: если старший бит установлен, восстанавливаем отрицательное значение через $\neg(a \oplus \text{mask})$.

```python
def get_sum(a: int, b: int) -> int:
    mask = 0xFFFFFFFF
    a, b = a & mask, b & mask
    while b:
        a, b = (a ^ b) & mask, ((a & b) << 1) & mask
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)  # restore the sign
```

**Типовые задачи:** Sum of Two Integers.

Сложность: $O(w)$, $w = 32$.

## Bitmask как компактное множество

**Сигнал.** Подмножества маленькой коллекции ($n \lesssim 20$); состояние «какие элементы уже использованы»; сравнение множеств символов на пересечение.

**Идея.** Подмножество $n$ элементов кодируется числом из $[0, 2^n)$: бит $i$ — «элемент $i$ взят». Проверка членства — $(m \gg i) \wedge 1$, добавление — $m \vee (1 \ll i)$, удаление — $m \wedge \neg(1 \ll i)$, пересечение множеств — просто AND. Цикл `for mask in range(1 << n)` перебирает все подмножества итеративно — плоская альтернатива рекурсивному перебору из [[backtracking]]. На этом же коде держится bitmask-DP: состояние — маска использованных элементов, $O(2^n)$ состояний (TSP, Partition to K Equal Sum Subsets).

```python
for mask in range(1 << n):
    subset = [items[i] for i in range(n) if mask >> i & 1]
```

**Типовые задачи:** Subsets (итеративно), Maximum Product of Word Lengths, Partition to K Equal Sum Subsets.

Сложность: перебор всех подмножеств — $O(2^n \cdot n)$.
