# wiki-ingest

Перенос PDF → `.md`-заметка под `wiki/`. **Дословный перенос, не пересказ.**

## Главное правило — переносим, а не переписываем

Это НЕ авторская заметка по `styleguide.md`. Содержание PDF переносится как есть: тот же текст, та же структура, те же заголовки и списки, тот же порядок. Запрещено сокращать, перефразировать, переставлять, дополнять «интуицией» или «мы»-голосом, исправлять авторские формулировки.

Из `styleguide.md` применяем **только то, что чинит отображение в Obsidian**, и ничего больше:

- **Математика → LaTeX.** Inline `$...$`, выносная `$$...$$` с разделителями на отдельных строках; многострочные выкладки в `\begin{aligned}` (голый `\\` в `$$` KaTeX игнорирует). Любой символ из текстового слоя/скриншота (`σ`, `≤`, `x_t`, `∑`) — командами LaTeX, не Unicode и не в backticks.
- **Картинки → эмбеды с путём** `![[images/<topic>/<file>]]`, сразу после абзаца, который на них ссылается.
- **Таблицы** — markdown-таблицами.

Всё остальное из styleguide (язык, регистр, ход вывода) к ingest **не применяется**. Frontmatter нужен.

## Инструмент

`scripts/extract_pdf_images.py` (PyMuPDF; зависимости объявлены инлайн по PEP 723, `uv run` ставит их сам). Три подкоманды cheap → expensive:

```
S=.claude/skills/wiki-ingest/scripts/extract_pdf_images.py
uv run $S text     --pdf in.pdf [--pages 1-5]   # текстовый слой + статистика по страницам
uv run $S embedded --pdf in.pdf --out-dir wiki/images/<topic> --prefix <name>   # чистые растровые фото
uv run $S render   --pdf in.pdf --pages 5 --out-dir wiki/images/<topic> --prefix <name> [--bbox x0,y0,x1,y1]  # рендер страницы/кропа
```

## Чек-лист (продублируй как TodoWrite)

1. **Назначение.** Спроси/выведи topic-папку (`wiki/<topic>/`), имя заметки и `<prefix>` для картинок (например, `lesson3`). Картинки идут в `wiki/images/<topic>/`.
2. **`text`.** Сними текстовый слой со статистикой. В шапке каждой страницы — `chars` / `images` / `drawings`. Классифицируй: много `chars` → текст переносится из дампа; мало `chars` при больших `drawings`/`images` → страница визуальная (вёрстка формул, диаграмма, скан), текстовый слой ненадёжен.
3. **Визуальные страницы — глазами.** `render` такие страницы и прочитай PNG. Формулы перенеси как LaTeX, текст со скана — вручную.
4. **Картинки.** Чистые фото/растр — `embedded`. Векторные диаграммы, графики, схемы — `render` с `--bbox` (кроп нужной области; bbox в точках PDF, см. координаты блоков в дампе `text`). Складывай в `wiki/images/<topic>/`.
5. **Сборка `.md`.** Перенеси текст дословно, в исходном порядке; вставь эмбеды картинок там, где они стоят в PDF; почини математику и таблицы. Больше ничего.
6. **Проверка.** Открой заметку: все `![[...]]` указывают на реально записанные файлы; выносные `$$` на отдельных строках; нет Unicode-математики и математики в backticks; структура совпадает с PDF.

После ingest содержимое `wiki/` изменилось → предложи прогнать **wiki-reindex**.

## Деградация

PyMuPDF нет — `uv run --with pymupdf ...` ставит его на лету.
